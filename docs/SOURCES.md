# Źródła merytoryczne

## Zasada wykorzystania

Pytania w aplikacji są autorskie. Źródła służą do ustalania zakresu nauczania, sprawdzania faktów, zasad bezpieczeństwa i dobrych praktyk. Treści nie zostały skopiowane z gotowych testów.

Każde zadanie w `public/data/tasks.json` ma pole `sourceKeys`. Klucze odpowiadają wpisom w `public/data/sources.json`.

Przypisanie klucza źródła nie oznacza, że instytucja zatwierdziła konkretne pytanie albo całą aplikację.
