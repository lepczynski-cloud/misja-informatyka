# Bezpieczeństwo

Projekt jest statyczną aplikacją przeglądarkową. Nie ma backendu, logowania, analityki ani centralnej bazy danych.

Problemy związane z bezpieczeństwem proszę zgłaszać prywatnie przez dane kontaktowe dostępne na profilu autora zamiast publikowania szczegółów podatności w otwartym zgłoszeniu.

Nie należy dodawać do repozytorium kluczy API, haseł, danych uczniów ani innych danych osobowych.
